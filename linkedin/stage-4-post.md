# Stage 4 — LinkedIn post (dashboard)

**Images:** `images/stage4_overview.png` (main), `images/stage4_products.png`

---

I've been working on the dashboard part of my customer support project, and this one taught me more about design than I expected.

The data was ready: 8,469 tickets cleaned in Excel, the business questions answered in SQL, and the findings tested in Python. The challenge now was making all of that clear in a few seconds for someone who doesn't want to read a report.

So I built three pages in Power BI. One overview with the main numbers, one for products and one for backlog and priority. Each page ends with a single sentence saying what the data means, because a chart without a conclusion just leaves the work to the reader.

The design choice I'm happiest with: I kept everything in blue and grey, and used red only once. Samsung Galaxy is the only product that survived the statistical tests from last week, so it's the only thing on the dashboard that stands out.

I also saved the report as a Power BI project instead of a normal file, so every page and measure can be versioned in Git like code.

Next step is the executive summary, the short version a manager would actually read.
